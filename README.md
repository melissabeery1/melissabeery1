# Melissa Beery

Animation producer, most recently at Netflix. Now I make AI films and build the tools behind them.

Most of my code lives in private repos. Here's what's live.

## Tools

**[Call Sheet](https://callsheetbymelissabeery.netlify.app/?from=github)** ranks 79 AI image and video models for a specific creative job, with a reason for each and a prompt written in that model's house style. Free, no account.

**[Prompt Sheet](https://promptsheetbymelissabeery.netlify.app/?from=github)** keeps the prompts you write and the ones you find online. It reads screenshots and turns the parts of a prompt you'd swap into blanks. Free, no account.

**[Capture the Light](https://capture-the-light.vercel.app/?from=github)** reads how an AI frame was lit and exports the setup as a Blender scene, so the rig can be rebuilt in CG.

**[StackWise](https://stackwise.melissabeery.com/?from=github)** grades a supplement stack from typed names or photos of the bottles. Built for a phone.

## Private builds
